Responsive static storefront for displaying Free Fire BD UID top-up packages and collecting order details through a prefilled WhatsApp message.

## Files
- `index.html` — page structure
- `styles.css` — responsive dark gaming theme
- `app.js` — package catalogue, search, filters, selection and WhatsApp order form

## Deploy on GitHub Pages
1. Upload all files to the root of your `hrtopup` repository.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch `main` and folder `/ (root)`, then Save.
5. Wait for GitHub Pages to publish the site.

## Important limitations
This is a front-end-only website. It does **not** verify bKash payments, store orders in a database, provide a working wallet balance, approve deposits, or deliver diamonds automatically. WhatsApp opens a prefilled message; the customer must review and press Send. Orders and payments must be checked manually by the store operator.

For a real wallet/admin dashboard, connect a secure backend (for example Firebase with strict security rules and trusted server-side validation). Never ask customers for their bKash PIN or OTP. Confirm current package prices and fulfilment availability before accepting payment.

HR TOP UP is an independent storefront and is not affiliated with or endorsed by Garena.
